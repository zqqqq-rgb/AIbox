# 远程访问与扫描首批实施记录

日期：2026-11-09。承接第二阶段第四批的任务页面与时间计划，落实产品建议中的远程授权、访问地址适配和相机发现体验。本批保留既有任务调度及配置恢复行为。

## 1. 已交付

1. 新增 `AccessSession`：配置凭据登录、随机内存会话、30 分钟过期、退出撤销、HttpOnly Cookie、Cookie 请求 Origin 检查，保留 Bearer 客户端兼容。
2. HTTP API、截图、录像文件与 WS 共用授权；未经授权不能订阅检测消息，退出或过期后关闭已有会话 WS。
3. 严格校验 `public_base_url`、`public_ws_url` 和信令路径。HTTPS 入口使用 WSS，对外信令和录像地址使用配置入口，不包含 ZLM secret。
4. 前端增加登录与退出、失效重登、连接重试和前后端版本不一致提示；登录凭据不通过页面持久保存。
5. 扫描支持网卡选择、受限 CIDR、总时限、1024 目标上限、32 并发和同进程扫描互斥；返回来源、确认状态与诊断计数。
6. 扫描页面展示已等待时间、部分结果与候选状态；相机配置已保存但待应用时不显示已连接成功。
7. 任务页补充按需加载真实快照底图及失败示意；修正启停终态分类、保守编辑准入、输入校验和过期异步回调。
8. 交付受控 Nginx 路由和远程配置模板，详见《AIBox_远程访问与扫描部署说明_V1.0.md》。

本批没有新增数据库迁移。会话随进程重启失效；仍使用单一配置访问凭据，未实现完整账号/RBAC。

## 4. 2026-11-10 补充：Nginx HTTPS/WSS 联调

使用 Nginx 1.28 Alpine、一次性自签证书和独立临时 fake 业务栈，在本机回环地址 `https://127.0.0.1:18443` 验证部署模板。只替换 upstream 端点，其余代理与鉴权规则使用交付模板。

- `nginx -t` 成功。
- 浏览器 7 组检查全部通过，无未捕获页面异常。
- 经 HTTPS 登录得到 Secure + HttpOnly 会话 Cookie；使用前端实际地址构造函数建立 WSS 连接成功。
- 模拟初始化失败可重试恢复，旧 localStorage Token 不会跳过会话建立。
- 经反向代理完成任务草稿保存、启用、停用及快照失败反馈。
- 已授权媒体信令能到达模拟 ZLM；退出后媒体信令返回 401，ZLM 管理路径返回 404，API 和证据文件返回 401。
- 扫描界面使用拦截返回验证，未实际扫描现场网段。

证据目录：`doc/validation/2026-11-10/proxy-browser/`。测试忽略一次性证书的信任错误，仅适用于本机验证。信令返回来自模拟服务，本次没有真实 SDP 媒体协商、视频播放、NAT 穿透或公网验收。

临时测试容器、网络和证书在验证后清理，既有学习演示数据库保持原样。
